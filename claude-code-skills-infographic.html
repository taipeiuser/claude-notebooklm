Skills 運作流程
📁
建立
在 .claude/skills/ 建立目錄與 SKILL.md
→
🔍
掃描
Claude 讀取 YAML frontmatter（~100 tokens）決定相關性
→
⚡
觸發
自動觸發 或 /skill-name 手動調用
→
🚀
執行
載入完整指令（<5K tokens）執行任務
SKILL.md 格式範例
~/.claude/skills/youtube-research/SKILL.md

YAML Frontmatter（控制觸發）

--- name: youtube-research description: 分析 YouTube 頻道熱門影片。 當使用者要研究 YouTube 影片時觸發。 disable-model-invocation: false allowed-tools: Bash, Read, Write argument-hint: [channel-url] ---
# 欄位說明 # name → 斜線指令名稱 # description → 觸發條件（LLM 判斷） # allowed-tools → 限制工具存取 # disable-model-invocation: true # → 只能手動 /skill-name 觸發

Markdown 內容（執行指令）

# YouTube Research Skill
## 執行步驟
1. 取得頻道 URL：$ARGUMENTS 2. 搜尋最近 10 支最熱門影片 3. 記錄標題、觀看數、連結 4. 分析內容模式與成功因素 5. 輸出至 youtube-research.md
## 輸出格式 - 影片標題 | 觀看數 | 連結 - 關鍵洞察：該頻道的勝出公式
