一、什麼是 Claude Code Skills（代理技能）？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Claude Code Skills 是 Anthropic 於 2025 年 10 月 16 日正式發布的功能，允許使用者透過一個名為 SKILL.md 的標準檔案，為 Claude AI 擴充客製化技能。

每個 Skill 是一個資料夾，包含：
- SKILL.md（必要）：以 YAML frontmatter 定義觸發條件，以 Markdown 撰寫執行指令
- 可選支援檔案：範例、腳本、參考文件

Skills 可透過兩種方式觸發：
1. 自動觸發：Claude 根據 description 欄位判斷是否相關，自動載入
2. 手動調用：使用者輸入 /skill-name 斜線指令

Skills 採用「漸進式揭露（Progressive Disclosure）」設計：
- 掃描階段：每個 Skill 只消耗約 100 tokens 的 description 元資料
- 觸發後：完整 SKILL.md 載入，不超過 5,000 tokens
- 按需載入：輔助腳本和資源只在需要時才讀取

Skills 遵循 Agent Skills 開放標準（agentskills.io），與 Claude Code、Cursor、Gemini CLI、OpenAI Codex CLI、GitHub Copilot 相容，一次撰寫，跨平台通用。

三、SKILL.md 格式技術說明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

每個 SKILL.md 檔案由兩部分組成：

第一部分：YAML frontmatter（控制觸發邏輯）
---
name: skill-name              # 斜線指令名稱（/skill-name）
description: 描述何時使用     # Claude 用來判斷是否載入（關鍵欄位）
disable-model-invocation: false  # true = 只能手動觸發，防止自動調用
user-invocable: true          # false = 隱藏於選單，只有 Claude 可觸發
allowed-tools: Read, Write    # 限制此 Skill 可使用的工具
context: fork                 # 在隔離子代理中執行
---

第二部分：Markdown 內容（執行指令）
提供給 Claude 的詳細步驟說明、模板、範例和參考資料。

支援動態變數替換：
- $ARGUMENTS    — 斜線指令後的所有參數
- $ARGUMENTS[0] 或 $0 — 第一個參數（位置索引）
- ${CLAUDE_SESSION_ID} — 目前 session ID
- ${CLAUDE_SKILL_DIR}  — Skill 所在目錄路徑

執行方式：
- !`bash command` 語法可在 Skill 內容送給 Claude 前執行 Shell 指令
- 輸出結果直接注入 Skill 內容（預處理，非 Claude 執行）
